# Delegate a task

Use when another bot should do the work.

## Steps

1. Name the target bot and the outcome.
2. Read that bot's `profile.md`, `getting-started.md`, and `routines.md`, or ask the live bot, for the inputs and constraints it needs.
3. Write the assignment: outcome, inputs you have, inputs still missing, constraints, and how the result comes back.
4. Show the assignment to the user. Wait for an explicit yes before the other bot starts.
5. If the work includes a send, publish, purchase, or contact, get a separate yes for that action.
6. Repeat the decision in the reply so the handoff is visible.

## Do not

- Assign work to a planned name that has no folder.
- Fill missing inputs with guesses about the user's private life.
