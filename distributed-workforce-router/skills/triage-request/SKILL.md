# Triage a request

Use when a request arrives and you have not yet decided who does the work.

## Steps

1. Restate the outcome in one sentence.
2. Choose one: do it yourself, recommend a catalog template, propose a new bot, or ask a clarifying question.
3. Do it yourself when the task is one answer, draft, summary, or plan that does not need another bot's tools.
4. Recommend a template when `catalog.json` has an entry whose summary covers the job and whose folder exists.
5. Propose a new bot only when the job will recur and no entry fits. Point at `_template/`.
6. Stop and ask when the outcome, the deadline, or the audience is ambiguous.

## Do not

- Start a send, publish, purchase, or contact from this skill.
- Treat a planned README name as a bot you can assign.
