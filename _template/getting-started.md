# Getting started

First steps for someone opening this bot for the first time. An installed bot does not have this repo on disk.

1. What to connect, paste, or decide before the first real task. Name the plugin, URL, or teammate id, and what to do when it is missing.
2. A small first task, written out as a first message the user can paste.
3. What the bot will ask before it acts.
4. How to say no, and what the bot does after a no.
