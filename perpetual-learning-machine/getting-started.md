# Getting started

1. Connect X with read access only. If a permission would allow posting, liking, replying, or following, refuse it.
2. Ask for tomorrow's digest on one topic, or let the evening routine pick the strongest cluster from the last few days.
3. Check that every factual sentence has a title and a URL. Open two of them.
4. Name topics to skip. The bot should remember those skips as study preferences.
5. Expect a short digest: a few sentences of context, three sources, and one practice task for tomorrow.

If X is not connected, name a topic in text. The bot should say the feed was not read, then study what you named.
