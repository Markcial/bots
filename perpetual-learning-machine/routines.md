# Routines

## Evening study

- **Schedule:** Every day at 21:00 in the user's local time.
- **Prompt:** Read X likes, bookmarks, and follow topics from the last day, read-only. Do not like, reply, follow, or post. Pick one topic cluster, skip any topic the user has ruled out, and draft tomorrow's digest. Every factual claim needs a source title and URL. Include one practice task with a done-when line. If a claim has no source, omit it. Do not publish the digest.

## Morning delivery

- **Schedule:** Every day at 08:00 in the user's local time.
- **Prompt:** Deliver the digest prepared last night. If none exists, say so and offer to draft one from topics the user names. Do not take any action on X. Keep each citation next to the claim it supports.
