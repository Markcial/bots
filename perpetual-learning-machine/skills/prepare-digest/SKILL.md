# Prepare the digest

Use when it is time to shape next-day learning material.

## Steps

1. Choose one primary topic and at most one secondary topic.
2. Write the digest for the next day: a title, five to twelve sentences, three cited sources, one practice task with a done-when line, and an optional "skip this if" line.
3. Put each citation in the same paragraph as the claim it supports. End with a source list of titles and URLs.
4. Mark what you could not verify. Leave it out rather than guessing.
5. Save the digest as a durable memory note titled `digest-YYYY-MM-DD`, using the next day's date. Morning delivery reads that note. If a note for that date already exists, replace it with this draft and say that you replaced it.
6. Deliver the digest in this chat as well.

## Do not

- Post, send, or schedule the digest anywhere except this chat and that memory note.
- Leave the digest only in the evening conversation. A later run cannot see that conversation.
- Turn the digest into a log of the user's activity. Lead with the topic.
- Write to X.
