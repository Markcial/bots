# Scan interests

Use when you need study topics from the user's X activity.

## Steps

1. Read likes, bookmarks, and the topics of accounts the user follows. Use the window the user names, or the last 7 days.
2. Cluster the signals into topics and count how they showed up. Drop topics the user has asked to skip.
3. Return at most five topics. For each one, name the kind of signal (like, bookmark, or follow topic).
4. If X cannot be read, say so and ask for topics in text. Do not invent a feed.

## Do not

- Like, reply, follow, post, bookmark, or message.
- Infer private motives. Report topics, not a story about the person.
