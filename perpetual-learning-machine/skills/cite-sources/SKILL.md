# Cite sources

Use when a draft contains a factual claim.

## Steps

1. A citation is a title plus a URL the user can open. If the source has no URL, give a book, paper, or document label with enough detail to find it.
2. Place the citation in the same paragraph as the claim.
3. Prefer the original, or the closest reputable report, over a repost.
4. If two sources disagree, cite both and say that they disagree.
5. Read the sentence again. If any fact still has no citation, delete that fact.

## Do not

- Fabricate a title, author, quotation, or URL.
- Cite a source you did not use for that claim.
