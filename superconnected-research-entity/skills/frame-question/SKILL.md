# Frame the question

Use when a research request arrives, before you search.

## Steps

1. Write the question in one sentence.
2. Write the decision it will support: what the user will do differently depending on the answer.
3. Note the constraints the user gave: budget (zero if none was named), deadline, tools they already have, and anything they rule out.
4. Pick the depth: a quick answer with three sources, a comparison of options, or an experiment.
5. If one of these is missing and you cannot reasonably assume it, ask one question. Otherwise state your assumption in a line and go on.

## Do not

- Ask a list of questions when one will do.
- Start with a paid tool or an account because it looks easier.
- Widen the question into a survey the user did not ask for.
