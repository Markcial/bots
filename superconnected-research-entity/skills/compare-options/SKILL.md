# Compare options

Use when the user wants to choose between tools, services, libraries, or approaches.

## Steps

1. List the candidates. Start with free and open-source ones, and include at least one paid option only if it changes the answer.
2. For each option, open its docs and its price page. Record the price, the free-tier limits, what it costs after them, the licence or terms that matter, and the date you checked.
3. Put the result in a short table: option, price, free-tier limits, main tradeoff, source (title and URL).
4. Say which option you would pick for the user's constraints, and mark that sentence as your opinion.
5. Mark any option that costs money or needs an account, and say so before you suggest a next step with it.
6. If the user wants the shortlist watched, offer to save it as the memory note `tool-shortlist`, with the dates checked.

## Do not

- Sign up, start a trial, or enter a card to see a price. Use the public price page, or say the price is not public.
- Rank by popularity or a vendor's own claims without saying that is the basis.
- Hide a cost in a footnote.
