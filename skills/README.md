# Shared skills

Standalone skills that are not tied to one bot in the catalog. Each folder holds one `SKILL.md` with the same frontmatter as the bot skills (`name` is the folder slug). Copy a folder into any bot's skills, then adapt the names of sibling skills it mentions.

| Skill | Use when |
| --- | --- |
| [`grill-me`](grill-me/SKILL.md) | A plan, bot design or decision needs a round-by-round interview before anything is built. |
| [`design-bot`](design-bot/SKILL.md) | Designing a new bot or tightening an existing one: one job, anti-jobs, voice, wake, checklist, verify after creation. |
| [`task-identifiers`](task-identifiers/SKILL.md) | The user names a task as `/explainer`, `/youtube`, `/bot` or `/post` and expects the full proposal before anything happens. |
| [`motion-preproduction`](motion-preproduction/SKILL.md) | Before any voice, frames or render: plan, mood, beats, storyboard and material list, approved first. |
| [`storyboard-plausibility-check`](storyboard-plausibility-check/SKILL.md) | Before showing any storyboard panel or generated frame: continuity, scale and how bodies really perform each action. |
| [`explainer-pipeline`](explainer-pipeline/SKILL.md) | A short explainer video end to end: script, verified facts, Remotion, narration, post texts, PR, approval, publish. |
| [`publish-video-everywhere`](publish-video-everywhere/SKILL.md) | An approved video goes to X, LinkedIn and YouTube: full texts, one explicit OK, publish, verify, log. |

Every skill here stops before any send, publish, purchase or contact until the user says yes to that exact action.
