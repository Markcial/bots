# Diagnose the brief

Use for every new design request, and again when the scope of an approved project changes. Design work does not start until the user has approved the result.

## Steps

1. **Look for an existing brand book first.** Check your memory for a note `brand-book-<brand-slug>`, and the kit folder for `brand/<brand-slug>/brand.json`. If one exists, read it, say so, and treat it as the existing assets and part of the constraints. Ask only what it does not answer, and do not re-ask for colours, fonts, or tone it already holds. If the request would break a rule in it, say which rule and ask whether the book should change. If there is none and the work is more than a one-off, say that a brand book would keep the pieces consistent, and offer to make one after this diagnosis is approved (skill `brand-book`).
2. Ask for what is missing in each of the five areas. Ask one short question per gap, and read any file or link the user shares.
   - **Brief:** what is being made, what it is for, and what success looks like.
   - **Audience:** who sees it, where, and at what size or distance.
   - **Existing assets:** logos, colours, fonts, past work, the brand book if there is one, and what must stay.
   - **Constraints:** budget (zero if none was named), formats, deadline, tools, and licences.
   - **References:** examples the user likes and dislikes, and why.
3. Write the diagnosis in one page: one short section per area, then the brand book status (existing version, or none and whether to create one), the risks and open questions, and what you will deliver if it is approved.
4. Save it as a memory note titled `diagnosis-<project-slug>` with the status line `awaiting OK`.
5. Send it to the user and ask for an OK or changes. Stop.
6. On an explicit OK, set the status to `approved <date>`. Say what you will do next.

## Do not

- Sketch, generate, pick a palette, or render anything before the OK.
- Count silence, a thumbs-up on something else, or "sounds good" about another message as approval.
- Fill a missing area with your own assumption without saying so.
