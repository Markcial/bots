# Licences used by this kit

The kit's own code is MIT, like the rest of the repository. It installs or calls these third-party tools. None of them is copied into this folder. Check each licence again before you rely on it for the owner (the monthly tool and licence check does this).

| Tool | Used for | Licence | Cost | Note |
| --- | --- | --- | --- | --- |
| [Remotion](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) (npm, pinned in `package.json`) | Rendering video and stills | Remotion License: free for an individual, a for-profit organisation with up to 3 employees, and a non-profit; a company licence is required for larger for-profit organisations | Free if eligible | **Ask the owner whether they are eligible before the first render.** Record the answer in `tool-notes`. If they are not eligible, stop and tell them the company licence has a price. |
| [React](https://github.com/facebook/react/blob/main/LICENSE) | UI inside Remotion | MIT | Free | |
| [FFmpeg](https://ffmpeg.org/legal.html) | Audio mix, mux, image resizing | LGPL/GPL, depending on the build | Free | The kit calls the installed `ffmpeg` program. It does not bundle it. |
| Remotion's headless Chrome | Frame rendering | Chrome for Testing / Chromium licences | Free | Downloaded into `node_modules` by `remotion browser ensure`. |
| [Phonon TTS](https://github.com/gradium-ai/xn-ptts) (`uvx ptts`) | Free local narration (optional) | Code: MIT OR Apache-2.0. Default model Phonon 31m and the voices: Apache-2.0 | Free | **Do not use the Phonon 40m models. Their weights are CC BY-NC 4.0 (no commercial use).** The kit never selects them. Check the model page on Hugging Face before changing the model. |
| [uv](https://github.com/astral-sh/uv) | Runs `uvx ptts` (optional) | MIT OR Apache-2.0 | Free | Installed by `setup.sh --with-tts`, with the owner's yes. |
| Built-in music (`scripts/music.mjs`) | Music bed | Generated by this kit's own code, MIT, no attribution | Free | No samples or third-party material. |
| Fonts | Type in videos and avatars | Whatever is installed on the computer; the default stack ends in `sans-serif` | Free | Use only open-licence fonts (SIL OFL, Apache-2.0). Record each font and its licence in `tool-notes`. |

Not covered by the above: paid image or video generators, stock libraries, and paid fonts. They are never used without the owner's yes, with the cost stated first.
